ROMAN ENGLISH — встановлення на iPhone

У ZIP є файли вебдодатка. Щоб встановити його як окремий додаток:
1. Спочатку потрібно опублікувати папку на HTTPS-хостингу (наприклад, GitHub Pages).
2. Відкрити отримане HTTPS-посилання в Safari на iPhone.
3. Натиснути Поділитися → На початковий екран (Add to Home Screen) → Додати.

Важливо:
- Сам ZIP ще не є встановленим додатком і не створює іконку автоматично.
- Для повноцінної роботи офлайн потрібне перше відкриття через HTTPS.
- Це стартова версія зі 100 базовими словами. Прогрес зберігається локально на пристрої.
- Вимова використовує голос en-US, доступний у Safari/iOS.
